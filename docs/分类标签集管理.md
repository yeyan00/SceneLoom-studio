# 分类标签集管理

2026-10-29。标签集属于通用点云分类模块，林业和其他插件按需消费语义。

## 使用与界面

- 入口：“点云编辑 → 管理标签集”，或左侧当前标签集名称/类别标题旁按钮。
- 未配置的新工程默认选中内置 **ASPRS LAS 1.4 R15**。分类前可以改选本机模板、复制标准，或新建项目标准。
- 管理器左侧为工程副本和本机标签库，右侧为定义列表；点击类别展开编辑区。桌面并排显示，窄屏纵向排列并滚动。
- 类别包含 `id`（0–255）、正式名称、多个别名、颜色、可选算法语义及保留标记。正式名称默认使用英文；别名可以是中文、行业名或其他语言，不受界面语言自动改写。
- 类别侧栏显示正式名称和别名，过长内容截断并通过标题查看全文；搜索支持名称、别名和 ID。
- “保存类别定义”更新管理器草稿；“应用到当前工程”才改变工程配置。关闭管理器可放弃未应用草稿。
- “保存到标签库”保存本机可复用模板；可以复制、改名、编辑、删除，并通过 JSON 导入导出。库模板被修改/删除后，工程副本保持原状。

**标签定义不会重写点的分类 ID。** 例如某项目定义 2=Building，原有分类值2仍然为2，只是解释为建筑。修改定义中的 ID 也不会迁移已有点；数值重映射是另一项数据操作，本版没有增加批量映射工具。删除定义后，原始数值仍保留；已加载节点或当前有效分类历史中发现的未定义 ID 显示为 `ID n / 未定义`，可在管理器补充。此检测不是全量类别统计。

标签配置修改会标记工程未保存，进入现有会话恢复、显式保存和工程打包；它不占用点编辑的 Undo/Redo 栈。分类、删除、单木编辑的撤销历史仍保存数值 ID，不随名称变化改写。

## 默认 LAS 标准

内置模板只读，修改需复制。采用 [LAS 1.4 R15（2019）](https://www.asprs.org/wp-content/uploads/2019/07/LAS_1_4_r15.pdf) 的分类表，包含0–18的定义/保留项。

- 0：Created, never classified；1：Unclassified；修正旧界面对0/1的模糊命名。
- 2：Ground；3/4/5：Low/Medium/High Vegetation；6：Building；7/18：Low Point (noise)/High Noise。
- 8、12在该版本为保留分类；模型关键点、重叠等使用分类标志位，不能与类别混为一谈。
- 19–63为该版本保留范围，64–255为用户可定义范围。没有把它宣传为所有 LAS 版本的最新统一表。

自定义项目可以采用其他编号标准，语义由项目明确配置，不按 ID、正式名称或别名推断。

## 工程与标签库数据

```json
{
  "id": "project-standard-a",
  "name": "Project A",
  "version": 1,
  "classes": [
    {"id": 2, "name": "Building", "aliases": ["建筑", "house"], "color": "#dfb6a1", "semantic": "building"},
    {"id": 42, "name": "Terrain", "aliases": ["地面"], "color": "#cbb08b", "semantic": "ground"}
  ]
}
```

- `shared/label-sets.mjs`：内置标准、校验、旧工程适配、语义解析和别名检索。
- `server/label-sets.mjs`：本机 `SCENELOOM_HOME/label-sets.json`，串行原子替换、版本冲突检查，最多128个用户模板。内置标准不写入用户文件。
- 工程 `project.db` 保存完整 `labelSet` 快照，兼容字段 `classes` 必须与快照一致；工程 JSON 仍只作为入口/索引。数据库升级到v3，v1/v2自动迁移，旧软件拒绝打开较新数据库。
- 旧工程有明确的标签集时直接使用；旧版原始默认8类迁移到内置标准；其他旧 `classes` 保留名称和颜色，但没有显式语义时按“无指定语义”处理，不把数字2猜作地面。
- JSON交换文件为 `{format: "SceneLoomLabelSet", version: 1, labelSet: {...}}`。导入为草稿，不自动替换工程或本机库。

## CHM 消费语义

CHM从当前工程标签集解析 `groundIds`、`ignoreIds` 和 `excludeCategories`，不再固定2=地面、6=建筑。地面支持点不足时，默认auto模式自动估计地面并归一化；无需预先做人工分类。显式选择“仅使用地面分类”仍会在无可用地面时报错。

建筑、水面、噪声按语义排除，地面按语义提供支持；最终自动单木归属也按捕获的类别集合排除。映射记录进分割命令，不会因为以后切换标签集而改变已确认结果。预览期间改动标签集后，旧结果禁止确认，需重新计算。

## 验证

- `npm.cmd run test:labels`：Playwright CLI 检查内置只读、新建、类别编辑、别名搜索、保存/删除模板、JSON往返、真实分类数值、工程重开和中英文窄屏。
- 单元：内置分类表与保留项、数字ID不推断语义、别名和配置脏状态、旧工程与独立副本、2=建筑/42=地面的CHM路径和无语义时自动估计。
- 接口：库并发版本冲突、项目保存/恢复/备份、删除库后项目仍可开、定义一致性校验、原始点云字节保持及CHM语义解析。
- 完整回归通过32个单元、11个接口及全部浏览器/转换检查。分类画刷391批反馈P95约8.8 ms、最大23.3 ms（合成10万点），未发现实时性退化；不是跨设备性能保证。

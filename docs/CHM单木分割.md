# CHM 单木分割基线

2026-10-30更新：已接入水平分块、重叠缓冲和边界实例融合。单次流式扫描生成受容量限制的累计栅格，再按块分割；不是每块重复扫描全部点云。参数、内存边界和实测见 [水平分块说明](CHM水平分块与边界融合.md)。结果总量200,000栅格的保护仍保留。

2026-10-29，第一版传统算法，作为自动初分及人工修正的起点。

## 使用

1. 打开 Potree，进入“林业 → CHM 单木分割”。
2. 当前存在“局部截取”区域时只处理该区域，否则处理整份点云。主视图当前可见 LOD 不限制计算数据。
3. 默认优先使用项目标签集明确指定的地面类别；没有足够地面支持栅格时自动估计。也可强制选择已有地面或自动估计。LAS默认地面ID为2，自定义项目可以不同，详见 [分类标签集管理](分类标签集管理.md)。
4. 调整像元、地面网格、最低树高、树顶间距、最小冠区面积和地面估计窗口，点击“计算分割”。支持进度及取消。
5. 查看俯视冠区预览。选择已有归属策略：默认“仅未分配点”保留人工结果；“转入当前单木”在此处表示允许分割结果覆盖已有归属。
6. 点击“应用分割结果”，一次生成树列表和点归属，一次 Undo 整体撤回，Redo 恢复。之后可以继续画刷、框选、移除和改名。
7. 保存工程或打包后可以重开；原始 octree.bin、hierarchy.bin 和 metadata.json 保留。

计算时捕获编辑历史和局部范围。分类、删除、历史、归属策略、参数或区域发生变化后，旧结果禁止确认，需重新计算；单纯相机变化不影响结果。计算完成前、预览阶段不产生编辑命令。为保持预览和实际颜色一致，生成预览时事务预留 ID；放弃预览会留下合法编号空隙。

默认参数：CHM 0.5 m，地面网格 2 m，最低树高 2 m，树顶间距 3 m，最小冠区面积 1 m²；地面估计窗口参数用于控制形态学邻域半径，上限半径默认 8 m。

## 当前算法与边界

- 遍历 Potree 2.0 DEFAULT/UNCOMPRESSED 层级，包括内部节点和代理块指向的子层级；所有层级点参与，不依赖显示预算。局部计算根据节点包围盒跳过不相交的点块，再做精确区域判断。
- 处理当前有效分类和删除历史；已删除点不参加计算。按项目标签集的明确语义排除建筑、水面、噪声，地面类别用作支持；LAS默认对应6、7、9、18和2，自定义标准不按这些数字猜测。回填实例时排除捕获的地面、建筑、水面和噪声类别；不包含完整 SOR 去噪。
- 地面分类充足时，以粗栅格地面低值、最近支持填充、中值平滑、双线性插值形成地面估计。否则使用低包络的渐进形态学开运算筛选支持点，属于近似估计，不是 CSF 或完整测绘级 DTM。
- 从最高点栅格减去地面估计形成 CHM；在有观测的邻域平滑，保留空像元屏障，不进行无约束跨空洞填冠。
- 局部极大值和树顶最小间距产生种子；最大容量优先洪泛实现标记控制分水岭，再过滤面积过小冠区。
- 栅格标签按 XY 回映射，点需达到最低离地高度。原始坐标始终保留；地面并非修改源点后“压平”。同一命令在已加载及后加载点上求值一致。

CHM 仍是二维树冠表达，不保证分开上下重叠的树或找出被遮挡下层树；离地高度阈值以下的树干点不会自动归入实例，需要人工补充。树顶间距过小容易过分割，过大容易漏检；最小面积按有观测 CHM 像元统计，并非精确树冠投影面积。局部范围未额外读取边界缓冲带，边缘可能截断树冠。密林缺少地面、陡坡、离群点和观测空洞均需检查。

**单次结果最多 200,000 个 CHM 栅格**，避免任务、历史和浏览器内存失控。0.5 m 像元约适合 220×220 m 以内的方形范围；大数据建议先局部截取。计算范围内已支持水平分块及边界实例合并；超出总量限制的磁盘分块处理仍待实现，不能把粗像元整幅计算视为等效结果。

## 实现位置

| 模块                          | 职责                                     |
| ----------------------------- | ---------------------------------------- |
| server/chm/algorithm.mjs      | 地面、CHM、树顶、分水岭，纯计算接口      |
| server/chm/potree-reader.mjs  | 校验层级与块长度，流式读取和空间跳过     |
| server/chm/worker.mjs         | 独立 Node Worker，全数据计算及进度       |
| server/chm/jobs.mjs           | 任务状态、取消、源数据验证和批量 ID 预留 |
| src/plugins/forestry/chm.jsx  | Ribbon 插件内的参数、预览与确认          |
| shared/chm.mjs / forestry.mjs | segmentTrees 命令与跨节点点归属          |

本版计算为 JavaScript 后台线程，不是 C++ EXE；计算模块与任务编排分离，后续可换原生工具，保持 UI 和结果契约。最多一个计算任务同时运行，最近完成任务最多保留8个、约30分钟后可清理；未确认的预览不跨进程恢复。确认后的结果不依赖任务缓存。

`segmentTrees` 作为单个 payloadVersion=2 命令保存：包含树定义、类型、地面栅格、正式 ID 标签栅格、范围、最低高度、归属策略、排除类别及算法参数。栅格存现有 project.db 命令负载，随 Undo/Redo/打包保存；不是逐点副本，也无需外置任务文件。代价是多次分割的历史体积会增长，未来可改不可变二进制资源引用。渲染 Worker 缓存大命令定义，后续画刷批次仅传命令 ID，避免反复克隆整张栅格。

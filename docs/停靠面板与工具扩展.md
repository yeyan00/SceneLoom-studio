# 停靠布局与工具扩展

2026-10-28，已实现的框架。

```text
顶部：标题 / 语言 / Ribbon
左侧：资产与类别   中央：三维视图   右侧：属性 | 工具箱
                  底部：日志（可隐藏）
状态栏：状态 / 点数 / 日志开关
```

右侧面板共用标签容器，切换属性与工具箱不会叠加侧边栏，也不重建点云 runtime。隐藏页保留表单和抽屉状态。工具箱不再作为中央底部面板；底部空间专用于按需打开的诊断输出。窄窗口的左右面板沿用浮层方式。

工具树按分类抽屉组织：如格式转换 → 点云转换 → Potree 转换。最多两段 category 加工具叶，共三级。自动处理分类可由本地工具扩充；当前不伪造尚未实现的处理工具。描述文件由后台加载，前端只接收工具 ID、分类、说明和参数；执行请求只能指定已注册 ID。宿主以 argv 直接启动 EXE，不拼接 shell 字符串。

工具注册、参数类型、执行目录与结果边界见 `tools/plugins/README.md`。现阶段注册需重启后台。该机制覆盖进程外工具，不等于已实现前端交互插件、热插拔或算法结果的自动编辑回写。

日志包含应用生命周期、数据打开、工程保存、历史变化、显示设置、工具选择、任务状态与输出、API/浏览器错误。按时间、级别、来源、消息及上下文记录为 JSONL；有任务时通过 jobId/工具 ID 关联。隐藏面板时后台照常记录，显示面板才轮询。

日志文件有轮转和容量限制，查询使用递增游标，过滤可以匹配上下文；导出包括仍保留的轮转文件。进程高速输出和极端写入积压会限流，不保证无限原始输出归档。任务状态当前驻留内存，应用重启后的任务恢复尚未实现；落盘日志可供排查。

验证：单元/服务测试覆盖日志轮转、重启和截断尾行恢复、工具深度约束、参数引用、独立进程传参与输出；playwright-cli 验证标签切换、抽屉搜索、实际注册 EXE 执行、隐藏日志记录、过滤导出和窄屏布局。原有真实点云的 10 种语言/尺寸布局及 6 种渲染组合回归通过。

# 画刷分类

## 使用

在主视图选择目标类别，点击“分类画刷”或按 B。按住左键涂刷，立即预览目标类别，松开完成一笔，不需再点击赋类。当前只支持穿透：圆形范围内前后点均参与；已设置局部区域时，仍受该区域限制。画刷不使用框选的深度开关，相关选区参数在画刷模式隐藏。

- `+` / `=`、数字键盘加号或 `]` 增大；`-`、数字键盘减号或 `[` 缩小。直径可输入，范围 4–512 CSS 像素。
- 涂刷期间相机禁止旋转、平移及缩放；允许改变画刷大小，每段记录实际半径。
- 松手后按住空格可导航，松开回到画刷。涂刷中按空格不切换导航。
- Esc 取消当前未提交笔画；空闲时 Esc 退出画刷。
- Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 按整笔撤销重做。活动笔画先取消，再操作已有历史。
- Ctrl+S 会先结束有效笔画，再保存确定的工程状态。失焦、窗口缩放、指针取消及区域/工具切换取消未提交笔画。
- 输入框及弹窗中不处理画刷快捷键。画刷仅在主视图工作；从最大化子视图进入画刷时切换到主视图。

## 实现

`src/editor/useBrush.js` 管理手势、圆环及快捷键；`shared/brush.mjs` 定义带版本的连续圆盘扫过轨迹。屏幕矩阵、参考视口、类别及局部范围在一笔开始时冻结。半径变化采用连续插值，快速移动也覆盖两次输入之间的路径。

新增 `brush` 选择叶节点，复用分类命令、分支历史、工程快照及打包。未加载节点以后按同一表达式应用；原 bin 不变。每笔最多 4096 个采样点，达到限额后结束有效笔画并提示松手继续，避免无限增长。

轨迹采用有界层次包围盒索引；节点先进行保守投影范围筛选。Worker 为每个节点缓存一份最近相机的点投影桶，当前笔画保留分类状态及已覆盖结果，后续输入仅检查新增轨迹附近的点。已是目标类别的点跳过重复赋值，删除点不参与。

预览采用一批执行、一批合并等待，输入轨迹不丢失。只有完整应用某批输入后才记录该批绘制反馈；取消和提交立即使旧版本失效，防止旧结果覆盖新状态。松手时若完整预览已计算，提升为正式历史缓存；未计算完的尾部仍需正确求值。

冷加载、Undo/Redo、重开与实时预览共用几何规范。单元测试比较增量与冷重放结果，并用独立密集圆盘采样核对变半径覆盖。

## 验证与性能口径

`npm.cmd run test:brush` 自动构建并运行浏览器测试。默认生成 10 万点样本，覆盖一笔一命令、实时预览、取消、尺寸快捷键及输入框隔离、相机锁定、实际空格导航、整笔 Undo/Redo、涂刷中保存、工程重开、中英文及窄屏。

性能基准为 50 ms，分别输出反馈 P50/P95/最大值、50 ms 内批次数及松手提交时间。测试包括 16/48/160/512 px 四种直径、连续修改不同类别，以及 240 次移动、途中改变半径的长笔画。

设置 `SCENELOOM_PERF_POTREE` 后可对实际大点云运行，工程与恢复数据仍隔离在测试临时目录，不改用户点云。测量为输入处理至覆盖相应轨迹的全部加载节点完成绘制提交，不等同显示器延迟；等待批次从最早待处理输入计时。结果依赖机器、当前视角、显示预算和缓存状态。完整本机数值见 [验证与性能记录](局部编辑验证与性能记录.md)。

本版尚无表面画刷、删除画刷、软边及压力输入；长时历史和持续数小时涂刷仍需专项验收。逐点属性编辑、物理导出和压实继续由后续工具实现。
